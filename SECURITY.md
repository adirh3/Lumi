# Security reporting

Please report suspected vulnerabilities privately to the repository maintainer
at **[support@fluentsearch.net](mailto:support@fluentsearch.net)**.
Use the subject **`[Lumi security]`** so the report is clearly identified as
concerning Lumi.

Do not open a public issue or pull request with exploit details. GitHub private
vulnerability reporting is not currently enabled for this repository; email is
the available private route.

Include the affected Lumi version or commit, OS/architecture, the security
impact and minimal reproduction steps using synthetic data. Redacted diagnostic
excerpts or a small proof of concept are useful. Never send account tokens,
API keys, passwords, confidential prompts, complete Lumi profiles or chat
databases.

Please coordinate public disclosure privately with the maintainer. This policy
does not promise a response deadline or a fixed support window for older versions.
For ordinary bugs or feature requests without sensitive security details, use
[GitHub Issues](https://github.com/adirh3/Lumi/issues).
