Install Lumi for Android

The native app uses the same Lumi conversations and interface as the web app, with Android's system keyboard and file picker.

1

Download the official APK

Lumi is not published in any app store. Get the official APK from GitHub below.

Matching this Lumi Desktop release.

Download Android APK

When the download finishes, open the APK and tap Install. Android may ask you to allow installations from this browser once.

2

Open Lumi

After installation, return to this page and continue. If Lumi is not installed, this button opens the official APK download instead of an app store.

Open Lumi
3

Enter the pairing code

Use the 6-digit code shown in Lumi Desktop. You only do this once.
